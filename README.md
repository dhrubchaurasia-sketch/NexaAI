# NexaAI

NexaAI is a full-stack AI assistant built using the MERN stack and Google's **Gemini 3.5 Flash API**. 
It enables users to engage in intelligent, real-time conversations with support for multiple chat threads and persistent chat history.

## Features

- Real-time AI conversations
- Google Gemini 3.5 Flash API integration
- Multiple chat threads
- Persistent chat history
- Responsive UI

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Google Gemini 3.5 Flash API
